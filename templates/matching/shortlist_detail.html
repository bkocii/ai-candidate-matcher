How the score is calculated

When both groups exist, must-have skills contribute 70 points and nice-to-have skills contribute 30. If only one group exists, it contributes all 100 points. Skills within a group are weighted equally. Missing skill evidence earns no points but is not treated as proof that the candidate lacks the skill.

Ranking order: score descending, then passed before needs-review only when scores tie, then stable record ID. Explicit hard-constraint failures are excluded regardless of score.
