# Synthetic Manual Testing Pack

Follow [`docs/manual_testing_guide.md`](../docs/manual_testing_guide.md) from the
project root. All names, contacts, identifiers, organizations, clients, job
descriptions, and CV contents in this folder are invented for software testing.

The fixtures are deliberately split into accepted and rejected examples. Do not
replace them with real candidate information unless you have an approved,
lawful, appropriately secured test process.

`synthetic-drita-shembull-cv.docx` is the unique accepted fixture used by the
reviewed bulk-intake walkthrough. The Arben and Amina fixtures deliberately
overlap candidates created earlier in the guide so duplicate handling can be
observed without real data.
